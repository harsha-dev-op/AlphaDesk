# Local NSE artifacts

This directory is for personal AlphaDesk research only. Place manually downloaded official NSE/NSE Indices artifacts directly in `inbox/`. Successful imports retain checksum-addressed copies in `raw/`; invalid or conflicting artifacts retain checksum-addressed copies in `rejected/` for operator review.

Bulk market-data files are Git-ignored and must not be redistributed. Public download availability does not grant redistribution rights. Keep only artifacts needed for local reproducibility and prune them manually and deliberately.
